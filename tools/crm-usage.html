CRM Usage

For every workflow, reads the most recent run CRM still has a record of (System Jobs, dialog sessions) through your own signed-in CRM session, and saves it as one small file crm-usage-<time>.json — dates, states and ids only. Every request is a read (GET); nothing in CRM is changed.

A record found proves the workflow ran. No record proves nothing: System Jobs are deleted routinely, real-time workflows log only failures, and business rules are never logged.

CRM Usage

One-time setup

  1. Show the bookmarks bar (Ctrl+Shift+B).
  2. Drag the CRM Usage button above onto the bookmarks bar. (Clicking it here does nothing useful.)

Each run

  1. Sign in to CRM as usual and stay on a CRM page, e.g. https://ahecrm.anadoluhayat.com.tr/main.aspx.
  2. Click CRM Usage on the bookmarks bar. It makes one or two small requests per workflow, so it takes several minutes; progress is visible under F12 → Console.
  3. When it finishes, the browser downloads crm-usage-<time>.json.
  4. In the extractor's appsettings.json, set "Run": { "UsageFile": "<full path to that file>" } together with ReprocessRunId (or ImportFile) and run it.

The file holds workflow ids and run dates, no record data. Keep it with the export all the same.
