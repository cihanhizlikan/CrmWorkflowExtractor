CRM Export

Reads every workflow definition and activation (with XAML), your privileges, option-set labels, process stages and the security roles that may start a process by hand, through your own signed-in CRM session, and saves them as one file crm-export-<time>.json.gz. Every request is a read (GET); nothing in CRM is changed. No person is named: role holders are counted and teams are named, but no user name leaves the server.

CRM Export

One-time setup

  1. Show the bookmarks bar (Ctrl+Shift+B).
  2. Drag the CRM Export button above onto the bookmarks bar. (Clicking it here does nothing useful.)

Each run

  1. Sign in to CRM as usual and stay on a CRM page, e.g. https://ahecrm.anadoluhayat.com.tr/main.aspx.
  2. Click CRM Export on the bookmarks bar. It takes several minutes on a large organisation, and the console names every stage as it goes; progress is visible under F12 → Console.
  3. When it finishes, the browser downloads crm-export-<time>.json.gz.
  4. In the extractor's appsettings.json, set "Run": { "ImportFile": "<full path to that file>" } and run it.

The downloaded file contains production workflow definitions, which may include URLs, user names or passwords. Keep it on the company computer; do not email it or paste it into a chat. Point the extractor at it as downloaded — do not unzip it first; it is read either way, by what it is rather than what it is called.
